# ভেকুর হিসাব খাতা

দুই ভেকুর দৈনিক হিসাব, মেরামত খরচ, ড্রাইভারের মজুরি ও বাকি, ডিজেলের দোকানের বাকি আর পাঁচ মালিকের ভাগ রাখার ওয়েবসাইট।

**সাইট:** https://mdjobaer131899-ai.github.io/veku-hisab/

## কে কী করতে পারে

| | মালিক | ড্রাইভার |
|---|---|---|
| লগইন | মোবাইল নম্বর + পাসওয়ার্ড | মালিকের দেওয়া মোবাইল নম্বর + পাসওয়ার্ড |
| দৈনিক হিসাব | লেখা, বদলানো, মোছা | ঘণ্টা আর ডিজেল পাঠায়, মালিক অনুমোদন করেন |
| জমা, খরচ, লাভ, মালিকদের ভাগ | দেখেন | দেখে না |
| ড্রাইভারের মজুরি ও বাকি | সব ড্রাইভারের | শুধু নিজের |
| ডিজেলের দোকানের বাকি | দেখেন ও শোধ লেখেন | দেখে না |

## প্রথমবার চালু করা

1. সাইট খুলুন। "মালিকের অ্যাকাউন্ট খুলুন" ফর্ম আসবে।
2. নাম, মোবাইল নম্বর, পাসওয়ার্ড আর **চালু করার কোড** দিন। কোডটি একবারই কাজ করে।
3. "মালিক ও সেটিংস" পাতায় মালিকদের নাম, প্রতিটি ভেকুতে কার কত অংশ, আর ডিজেলের দাম ঠিক করুন।
4. "ড্রাইভার" পাতায় ড্রাইভার যোগ করুন। লগইন দিলে সাইটের লিংক, মোবাইল আর পাসওয়ার্ড ড্রাইভারকে জানান।

## Supabase-এ যা করা দরকার

- **Authentication → Sign In / Providers → "Allow new users to sign up" বন্ধ করুন।** এতে বাইরের কেউ নিজে অ্যাকাউন্ট খুলতে পারবে না। মালিক যে লগইন দেন, শুধু সেগুলোই কাজ করবে।
- ফ্রি প্ল্যানে প্রজেক্ট এক সপ্তাহ কেউ না খুললে Supabase সেটা থামিয়ে রাখে। তখন Supabase ড্যাশবোর্ডে গিয়ে "Restore" চাপলে আবার চালু হয়, কোনো ডাটা হারায় না। প্রতিদিন হিসাব লিখলে এমন হবে না।

## মালিক পাসওয়ার্ড ভুলে গেলে

Supabase ড্যাশবোর্ড → SQL Editor-এ নিচেরটা চালান (নম্বর আর নতুন পাসওয়ার্ড বদলে):

```sql
update auth.users
set encrypted_password = crypt('নতুন-পাসওয়ার্ড', gen_salt('bf'))
where email = '01XXXXXXXXX@phone.veku-hisab.app';
```

## ফাইলগুলো

- `index.html`, `app.js`: ওয়েবসাইট
- `config.js`: Supabase প্রজেক্টের ঠিকানা আর পাবলিক key (এটা প্রকাশ করা নিরাপদ, ডাটাবেসের নিয়মই সুরক্ষা দেয়)
- `supabase/schema.sql`: ডাটাবেসের টেবিল আর নিরাপত্তার নিয়ম
- `supabase/functions/users/`: লগইন তৈরি আর পাসওয়ার্ড বদলানোর ফাংশন
